In each folder corresponding to a test network the trained RL models are tested for specific scenarios.

The GCAPS and MLP model can each be tested using the demonstration files 'TestGCAPS.py' and 'TestMLP.py' 

The solution obtained from the test files i.e. switching and load status can be further used to evaluate the circuit. For this use the 'EvaluateCircuit.py'

In the 'EvaluateCircuit.py' we have provided different combinations of scenarios and models that can be evaluated on the OpenDSS circuit.
